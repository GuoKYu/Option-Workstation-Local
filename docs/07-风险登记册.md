## 风险详情

### R1 / R4 根因对比（外部权限，最关键）
- **R1 期权行情**：权限包为「OPRA 美股期权行情 (OpenAPI)」，与 App/Web 同名项独立；缺则订阅通过不推数据 → `no usable quotes yet`。
- **R4 交易 API**：`live.rs:752-764` 以 `us_asset_overview()`/`account_balance()` 是否返回决定是否 `trade_connected`；二者皆 None → `trade` 不入库 → 接口报 `trade permission is unavailable for this token`。根因多为 OAuth scope 不含交易，或账户未开通 OpenAPI 交易（与市场/下单权限是两套）。

### R3 设计权衡
当前 65s 冷却为**单一全局时间戳**（非按标的分），手动切换与 90s 后台刷新共享窗口。无害但提示频繁，可选改进：按 `symbol` 分 `HashMap`、或后台与手动独立时间戳。
