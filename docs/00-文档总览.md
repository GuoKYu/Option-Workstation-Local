## 关键外部依赖（必读）

1. **长桥行情权限**：期权实时报价需单独开通 **「OPRA 美股期权行情 (OpenAPI)」**（App/Web 端同名权限不认 OpenAPI）。缺失时界面显示 *selected expiration has no usable quotes yet*。验证：`code=301604: no quote access`。
2. **Trade API**：当前版本显示 **Unavailable**（见 R4 清单）。即便开通，本版仅支持模拟账户(paper)模拟单，实盘锁定。
3. **限频保护**：期权请求 65s 全局冷却（`live.rs:47`），触发时前端排队提示约 59s 自动重试（无害）。

## 仓库结构

```
optionworkstation/
├─ rust-backend/        Rust(axum) 后端，端口 7311
├─ frontend/            React 19 + echarts 前端
├─ docs/                本文档包（11+ 份）
├─ docs-site/           离线 HTML 文档站（index.html，本地可点开）
├─ 操作手册.md           根目录实操手册
├─ build-local.bat      改动代码后重新编译+启动
├─ start.bat            日常启动（不重编）
└─ install-mingw-gnu.bat 首次 MinGW GNU 工具链安装
```

## 如何更新文档站

文档为静态 Markdown，修改 `docs/*.md` 后重跑构建即可生成离线站：

```powershell
cd docs-site
python build.py        # 输出 docs-site/index.html
```

离线站为单文件 HTML（含左侧导航、无外部网络请求），可直接双击打开或随仓库分发。
