## 1. 项目背景

OptionWorkstation 是一个**本地部署**的美股期权分析工作站，面向期权研究者、量化爱好者与交易前分析场景，提供期权链、波动率曲面建模、多腿策略损益分析与研究审计台账能力。项目首期以"本地单机、数据自管、免云端依赖"为原则交付，规避云端部署的账号/白名单复杂度。

当前版本 `0.1.0`（Apache-2.0）已具备可运行形态：后端 Rust（axum）编译产物 `option-workstation.exe` 于 2026-08-24 在本机编译成功，前端 UI 可正常渲染，长桥 OAuth 本地模式连通。

## 2. 项目目标

| 目标 | 说明 | 度量 |
|------|------|------|
| G1 本地可运行 | 双击脚本即可在 Windows 本机启动完整服务 | `http://127.0.0.1:7311` 可访问、UI 渲染 |
| G2 实时行情接入 | 通过 Longbridge OpenAPI 拉取正股与期权行情 | 正股报价+期权链可见；期权报价需 OPRA(OpenAPI) 权限 |
| G3 分析与建模 | 期权链（希腊字母）、波动率曲面（SVI/SVF）、多腿策略分析 | 各面板可出图/出数 |
| G4 研究可追溯 | 审计台账 append-only 记录分析动作 | 研究动作可回查 |
| G5 源码受控 | 全量代码 GitHub 管理（main 本地 / cloud 云端） | 双分支可追踪 |

## 3. 项目范围

### 3.1 范围内（In Scope）

- 本地 Windows 部署（MinGW GNU 工具链 + Rust）。
- 双模式：历史回放（replay）+ 实时（live）。
- 功能：期权链与希腊字母、波动率曲面（2D 热力图 / 3D SVI·SVF）、SVI 微笑拟合、多腿策略工作台与分析、审计台账、实时 WebSocket 流、Longbridge OAuth 2.0。
- 行情源：Longbridge OpenAPI（正股 `SubFlags::QUOTE`、期权 `SubFlags::DEPTH`）。
- 代码托管：GitHub（`GuoKYu/Option-Workstation-Local`）。

### 3.2 范围外（Out of Scope，本期）

- 云端公网部署（保留 `cloud` 分支与 `DEPLOY-CLOUD.md`，暂不在本期交付）。
- 实盘交易（Trade API 当前不可用，仅预留接口/模拟单）。
- 多资产类别（仅美股期权 + 对应正股）。
- 多用户/权限体系（单机单用户）。

## 6. 资源

- **计算**：本机 Windows 10/11，MinGW-w64 + Rust（GNU）。
- **网络**：crates.io（编译期，必要时手机热点）、Longbridge CN 节点。
- **账号**：Longbridge OpenAPI（需 OPRA(OpenAPI) 行情权限）。
- **代码托管**：GitHub（SSH 443）。

## 7. 高层风险（详见风险登记册）

- R1 期权行情权限缺失（OPRA OpenAPI）→ 期权无报价（**当前已确认根因**）。
- R2 受限网络导致编译/依赖下载困难（GitHub/微软/部分镜像被封）。
- R3 65s 期权请求全局冷却可能频繁触发排队提示。
- R4 Trade API 不可用，交易/模拟单功能暂挂。

## 8. 成功标准

1. 本机一键启动、UI 全面板正常。
2. 开通 OPRA(OpenAPI) 后，期权链/曲面/策略台端到端出数出图。
3. 全套配套文档（本包）齐备并通过评审。
4. 代码双分支受控、可追溯。
