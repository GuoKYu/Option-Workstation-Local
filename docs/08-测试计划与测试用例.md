# OptionWorkstation 测试计划与测试用例（STP）

> 文档版本：v1.0 ｜ 编制日期：2026-08-24 ｜ 关联：需求跟踪矩阵 `06`、验收标准 `09`

---

## 1. 测试范围
- 覆盖 `02-需求规格说明书.md` 全部 FR / NFR。
- 重点：行情权限（FR-04/R1）、交易 API（FR-19/R4）、限频保护（FR-15）、波动率曲面、策略分析、审计台账。

## 2. 测试类型
| 类型 | 说明 | 工具 |
|------|------|------|
| 单元测试 | 数值/分析函数（IV、Greeks、SVI 拟合） | `cargo test`（approx） |
| 集成测试 | REST/WebSocket 端点 | curl / 前端 E2E |
| 端到端 | 登录→订阅→曲面→策略→审计 | 手动 + 脚本 |
| 权限验证 | 期权/交易权限真值探测 | Longbridge CLI |

## 3. 测试环境
- Windows 10/11 + MinGW GNU + Rust (GNU)。
- Longbridge 账号：LV1(OpenAPI) + **OPRA(OpenAPI)**（R1 前置）。
- 已知受限网络：crates.io 用手机热点；GitHub SSH 443。

## 5. 准入/准出
- **准入**：代码编译通过（`build-local.bat`）。
- **准出**：FR-04/FR-19 在权限就绪后用例通过；无 P0/P1 缺陷遗留。
- **已知阻塞**：TC-04（R1）、TC-19（R4）依赖用户侧权限开通，列为「待外部条件」。

## 6. 缺陷等级
- P0：核心功能不可用（如无法启动、曲面全空）
- P1：重要功能受限（如期权无报价）
- P2：体验问题（如提示文案）
