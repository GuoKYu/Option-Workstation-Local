# OptionWorkstation 验收标准（Acceptance Criteria）

> 文档版本：v1.0 ｜ 编制日期：2026-08-24 ｜ 关联：需求跟踪矩阵 `06`、测试计划 `08`

---

## 1. 验收原则
- 每条 FR/NFR 至少有一项可执行验收项。
- 验收以「权限就绪后」为前置条件；外部依赖（R1/R4）未满足时明确标注「待外部条件」。

## 2. 验收清单

### 环境（前提）
- [ ] A-01 本机 `start.bat` 启动，`http://127.0.0.1:7311` 可访问。
- [ ] A-02 浏览器渲染全部面板（链/曲面/策略台/审计）。

### 鉴权与行情
- [ ] A-03 OAuth 本地模式登录成功（回调 localhost:60355，免白名单）。
- [ ] A-04 正股行情持续推送（SPY 报价刷新）。
- [ ] **A-05【待外部条件 R1】** 开通 OPRA(OpenAPI) 后期权链/深度/IV 可见；界面不再长期"no usable quotes yet"。

### 分析与建模
- [ ] A-06 期权链与 Greeks 计算正确（抽样比对）。
- [ ] A-07 2D/3D 波动率曲面渲染正常；无 WebGL 自动降级。
- [ ] A-08 SVI 微笑拟合并叠加曲线。
- [ ] A-09 replay 回放按分钟驱动曲面。
- [ ] A-10 live 会话建立、WebSocket 流推送。
- [ ] A-11 65s 限频提示无害、到点自动重试、行情不中断。

### 策略
- [ ] A-12 多腿策略损益/聚合 Greeks/盈亏平衡计算合理。

### 审计
- [ ] A-13 审计台账追加/查询正确，append-only 不被篡改。

### 交易（预留）
- [ ] **A-14【待外部条件 R4】** Trade API 可用性定位/解决后，`/api/trade/account` 返回账户；模拟单（paper）可提交。

### 非功能
- [ ] A-15 失败提示可理解、行情流不阻断（断网恢复自愈）。
- [ ] A-16 仅本机监听，token 不落盘。
- [ ] A-17 前端高頻切换不抖动（节流/取消生效）。

## 3. 验收结论分级
- **通过**：A-01..A-04、A-06..A-13、A-15..A-17 全部满足。
- **有条件通过**：A-05、A-14 待用户侧权限开通（R1/R4）后补充验收，不阻断主验收。
- **不通过**：任一非外部依赖项失败。
