## 1. 版本管理

### 1.1 语义化版本
采用 `MAJOR.MINOR.PATCH`（当前 `0.1.0`）：
- MAJOR：不兼容架构/接口变更
- MINOR：新功能（向后兼容）
- PATCH：修复/文档/配置

### 1.2 分支策略（GitHub `GuoKYu/Option-Workstation-Local`）
| 分支 | 用途 | 说明 |
|------|------|------|
| `main` | **本地部署主枝** | 日常开发与本地运行版本 |
| `cloud` | 云端部署分支 | 含 `OW_OAUTH_REDIRECT_BASE` 公网回调 + `DEPLOY-CLOUD.md`；与 main 隔离 |

- 推送：SSH over 443（`~/.ssh/config`：`HostName ssh.github.com Port 443`）。沙箱内可用；本机执行 `GIT_SSH_COMMAND="ssh -o StrictHostKeyChecking=no" git push origin main`。
- 建仓：GitHub MCP 无 `create_repository` 权限（403），**远程空仓须用户在网页创建**；本地仅对已存在仓库写。
- 同步：`git push origin main:cloud` 将本地主枝同步到云端分支。

### 1.3 提交规范
`<type>: <subject>`，type ∈ {feat, fix, docs, refactor, chore, test}。例：`docs: add operation manual`。

## 2. 配置管理

### 2.1 配置项（`.env`，本地 localhost 模式）
| 变量 | 默认值 | 说明 |
|------|--------|------|
| `OPTION_WORKSTATION_HOST` | 127.0.0.1 | 仅本机监听 |
| `OPTION_WORKSTATION_PORT` | 7311 | Web 端口 |
| `OPTION_WORKSTATION_DATA_ROOT` | ./data | 回放数据根 |
| `OPTION_WORKSTATION_RISK_FREE_RATE` | 0.043 | 无风险利率 |
| `OPTION_WORKSTATION_FRONTEND_DIST` | ./frontend/dist | 前端构建产物 |
| `OPTION_WORKSTATION_AUDIT_PATH` | ./.option-workstation/audit.jsonl | 审计台账 |
| `RUST_LOG` | option_workstation=info,tower_http=info | 日志分级 |
| `OW_OAUTH_REDIRECT_BASE` | （local 不设置） | 云端回调基址（cloud 分支用） |

### 2.2 编译期环境变量（build-local.bat 内）
- `CARGO_HTTP_SSL_NO_REVOKE=true`：规避 Windows Schannel 证书吊销检查失败。
- `RUSTUP_USE_RUSTLS=1`：强制 rustup 用 rustls（避 Schannel）。

### 2.3 工具链约束
- 工具链：`stable-x86_64-pc-windows-gnu`（**非 MSVC**）。
- MinGW：`C:\mingw64\bin`（gcc/ld）。
- cargo 配置：`rust-backend/.cargo/config.toml` 应为**空（零自定义源）**，依赖默认 crates.io + 上述环境变量。

### 2.4 依赖与补丁
- `Cargo.lock` 锁定版本，避免漂移。
- 本地 patch（`Cargo.toml` `[patch.crates-io]`）：`longbridge-oauth`、`dotenv`、`paste` 指向 `../vendor/*`，确保受限网络下可编译。

### 2.5 密钥与凭据
- Longbridge OAuth token：**进程内存只存**（代码标记 `credential_storage: "process_memory_only"`），不落盘。
- 不提交任何密钥/`.env` 实际凭据到仓库（`.env` 仅模板级，仓库内为本地配置，注意勿含个人 token 残留）。

## 3. 配置基线发布
每次发版须确认：工具链版本、`.env` 模板、前端 `dist` 已构建、`Cargo.lock` 一致。
