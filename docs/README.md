## 阅读顺序建议
1. 想**直接用**：先看根目录 `操作手册.md`。
2. 想**了解项目全貌**：`01 项目章程` → `02 需求` → `03 架构`。
3. 想**接手开发/测试**：`04 接口` → `08 测试` → `09 验收` → `10 配置版本`。
4. 想**把控风险/进度**：`05 计划` → `06 追踪矩阵` → `07 风险`。
