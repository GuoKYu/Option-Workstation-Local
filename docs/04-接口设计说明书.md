# OptionWorkstation 接口设计说明书

> 文档版本：v1.0 ｜ 编制日期：2026-08-24 ｜ 对应版本：app v0.1.0
> 说明：以下端点由 `rust-backend/src/main.rs` 路由装配，路径与行为以本机实测代码为准。

---

## 1. 通用约定

- Base URL：`http://127.0.0.1:7311`
- 内容类型：请求/响应均为 `application/json`（除 WebSocket 与静态资源）。
- 鉴权：Longbridge OAuth token 由后端持有（本地模式），前端不直接持密钥。
- 错误：JSON `{ "error": "..." }`；期权限频返回 HTTP 429 + 字段 `option_retry_after_ms`。

## 3. 行情与数据

| 方法 | 路径 | 说明 | 关键参数 |
|------|------|------|----------|
| GET | `/api/chain` | 期权链（合约/行权价/IV/Greeks） | `symbol`, `expiration` |
| GET | `/api/surface` | 波动率曲面数据 | `symbol` |
| GET | `/api/volatility-context` | 波动率上下文（微笑/曲面） | `symbol` |
| GET | `/api/replay/snapshot` | 历史回放快照 | `date`, `symbols` |
| GET | `/api/v1/replay/snapshot` | 回放快照（v1，前端主用） | `date`, `symbol`, `minute`, `expiration` 等 |

**响应示例（surface，节选）**
```json
{
  "grid": [ [ [moneyness, dte, iv], ... ] ],
  "points": [ { "moneyness": 1.02, "tte_days": 30, "iv": 18.5 }, ... ]
}
```

## 5. 实时模式（Live）

| 方法 | 路径 | 说明 | 关键参数/体 |
|------|------|------|-------------|
| POST | `/api/live/session` | 建立实时会话/订阅 | `{ symbol, max_contracts, surface_expiries, moneyness_window }` |
| GET | `/api/live/snapshot` | 实时快照 | — |
| GET | `/api/live/volatility-context` | 实时波动率上下文 | — |
| GET | `/api/live/stream` | **WebSocket** 实时行情流 | — |

> 订阅逻辑（`live.rs`）：正股 `SubFlags::QUOTE`，期权 `SubFlags::DEPTH`；期权请求受 65s 全局冷却（live.rs:47）保护。

---

## 9. WebSocket：`/api/live/stream`

- 协议：ws / wss（本机 ws）。
- 推送：实时 tick / 深度 / 快照增量。
- 消费：前端建立连接后按 `surfaceUpdateRef` 2s 节流更新曲面与读数。

---

## 10. 前端 ↔ 后端约定

- 前端 SPA 由后端静态托管（`OPTION_WORKSTATION_FRONTEND_DIST=./frontend/dist`）。
- 模式切换：URL `?mode=live|replay`；默认 replay。
- 全局错误：前端捕获 429 → 限频排队提示并 `setTimeout` 自动重试（App.jsx:379）。
